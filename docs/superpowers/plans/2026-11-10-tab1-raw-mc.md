## F-22 decisions (settle the spec's r6 Minors/Nits)

- **Step dates (M-1):** step k spans `[d_k, d_{k+1})`, `d_k = today + k calendar months` (same day of month, clamped to month length). A step belongs to the cycle containing `d_k`; its φ is measured at `d_k`; μ and σ use `t(d_k + 15 days)`.
- **Block grid (M-2, N-2):** within each cycle, blocks are consecutive runs of 3 steps starting at that cycle's first step; the last block of a cycle is 1–2 steps only in the current partial cycle or where the horizon cuts. A redrawn block keeps its grid slot and length, so it never crosses a projected halving. A short block of length L draws L consecutive months from one complete cycle, starting within φ ±0.04, same widening rules.
- **Test (a) (M-3):** `simulate` returns its own `schedule` (per block: cycle index, step slice, candidate start indices) and the `z_shift` it applied; the test recomputes E′ from exactly those objects.
- **Debias (N-1):** `z_shift = E / n`, E and n taken from the **first whole future cycle's** grid (n asserted == 48); computed the same way even when the horizon contains no whole cycle. Applied to every cycle-mode draw; Trend = None and independent mode use `z_shift = 0`.
- **Prototype figures (N-2):** spec figures are illustrative; tests pin only the spec's bounds.
- **D_0 (N-3):** `D_0 = D_lastME + log(P_today / P_lastME) − μ(t_today) · f`, `f` = fraction of the current month elapsed.
- **Thin partial cycle (N-4):** a cycle with < 12 data months standardises its months with the fitted trend's monthly μ, σ at each month's t (Trend = None: the window's pooled monthly mean and std). ≥ 12 months: its own sample mean/std.

## Review Focus

1. **Live price missing or stale** (`btc-price-store` empty/0): Raw must start at the last daily close, not 0 or NaN. → Task 5 test `test_raw_start_price_falls_back_to_last_close`.
